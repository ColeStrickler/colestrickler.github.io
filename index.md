<section id="research">
  <h2>Research Pillars</h2>

  <h3>On-The-Fly Data Transformation</h3>
  <p>What if applications could always access data in the layout best suited to their computation? The research goal is to give applications an optimal view of each data object—maximizing spatial and temporal locality—without requiring data duplication, explicit reorganization, or application-specific tuning.</p>

  <h3>Predictable Memory Systems</h3>
  <p>In multicore systems, memory requests from different cores compete for shared caches, interconnects, and DRAM resources. This interference makes memory-access latency depend on the behavior of concurrently running applications, undermining worst-case timing guarantees. The research goal is to develop new hardware structures that give applications strong, useful guarantees about memory timing while preserving the parallelism and performance of modern memory systems.</p>
</section>
